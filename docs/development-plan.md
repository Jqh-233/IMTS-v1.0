# IMTS 开发计划

## 原则

1. **增量、稳定**：每步只改一个模块，确保已有功能始终可用
2. **后端先行**：先出 API，再写前端；API 可用 curl/Swagger 验证
3. **每步提交**：一步一测，不攒代码
