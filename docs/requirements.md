# IMTS 需求规格

## 项目概述

IMTS（Intelligent Mail Task Synergy System）是一个小团队邮件任务管理工具。自动从邮箱抓取邮件、智能识别待办任务，以看板形式统一管理。

## 用户角色

- **团队成员**（3-10 人）：日常使用，管理个人邮件任务
- **管理员**（未来）：管理团队、配置系统

## 功能需求

### F1. 邮件同步

| ID | 需求 | 优先级 |
|----|------|--------|
| F1.1 | 连接 QQ 邮箱 IMAP，抓取近期邮件 | P0 |
| F1.2 | 邮件去重（按 message_id） | P0 |
| F1.3 | MIME 解析，提取主题/发件人/正文/时间 | P0 |
| F1.4 | HTML 邮件转纯文本 | P1 |
| F1.5 | 支持多邮箱账号 | P2 |
| F1.6 | 支持更多邮件服务商（Gmail, 163 等） | P2 |
| F1.7 | 按发件人/主题/文件夹过滤 | P2 |

### F2. 任务提取

| ID | 需求 | 优先级 |
|----|------|--------|
| F2.1 | 规则引擎：正则匹配提取任务 | P0 |
| F2.2 | LLM 引擎：DeepSeek API 语义提取 | P0 |
| F2.3 | Hybrid 模式：LLM 优先，规则兜底 | P0 |
| F2.4 | 过滤非任务邮件（广告、验证码、收据等） | P0 |
| F2.5 | 提取任务名、截止日期、优先级、分类 | P0 |
| F2.6 | 置信度标注（LLM 任务） | P1 |
| F2.7 | 低置信度任务进入人工确认区 | P1 |
| F2.8 | 用户反馈机制（"判断错了"按钮） | P2 |

### F3. 任务看板

| ID | 需求 | 优先级 |
|----|------|--------|
| F3.1 | 三栏看板：待办 / 进行中 / 已完成 | P0 |
| F3.2 | 任务卡片显示：名称、优先级、截止日、分类 | P0 |
| F3.3 | 状态流转（待办→进行中→已完成） | P0 |
| F3.4 | 任务搜索（按名称模糊匹配） | P0 |
| F3.5 | 优先级筛选 | P0 |
| F3.6 | 排序（截止日/优先级/创建时间） | P0 |
| F3.7 | 手动创建任务（不依赖邮件） | P1 |
| F3.8 | 任务编辑（名称/截止日/优先级/分类） | P1 |
| F3.9 | 任务删除 | P1 |
| F3.10 | 邮件溯源（任务→原始邮件） | P1 |
| F3.11 | 日历/时间线视图 | P2 |
| F3.12 | 任务拖拽排序 | P2 |

### F4. 配置管理

| ID | 需求 | 优先级 |
|----|------|--------|
| F4.1 | 邮箱账号配置 | P0 |
| F4.2 | LLM API 配置 | P0 |
| F4.3 | 提取模式切换 | P0 |
| F4.4 | 配置持久化存储 | P0 |

### F5. 系统

| ID | 需求 | 优先级 |
|----|------|--------|
| F5.1 | 本地数据存储（SQLite → PostgreSQL） | P0 |
| F5.2 | 用户登录与数据隔离 | P1 |
| F5.3 | 操作日志 | P2 |
| F5.4 | 桌面通知（临近截止日） | P2 |

## 非功能需求

- **性能**：首次加载 <2s，邮件同步 10 封 <10s
- **可用性**：新成员 15 分钟内上手
- **安全**：邮箱授权码加密存储，不在前端回显
- **兼容性**：Windows 10+，Chrome/Edge 浏览器
